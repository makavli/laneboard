# Roadmap

Free to make, free to use: everything runs on the user's PC, no server, no account, no telemetry.

| Milestone | Status | Goal |
|---|---|---|
| 0.1 First light | done | Tray flyout, Light/Advanced views, themes, glass-to-solid, GitHub through `gh` |
| 0.2 Solid | done | Opens on the tray's monitor and taskbar side · instant updates on file changes · crash log |
| 0.3 Needs-you | planned | Windows notifications (checks fail/pass, new safe point, runner offline) · tray badge · needs-you first |
| 0.4 Polish | planned | Pin projects · refresh interval · subtle motion · keyboard navigation · accessibility pass |
| 0.5 Ship-ready | planned | MSIX with a startup task · Store screenshots · privacy text · README GIF |
| 1.0 | planned | Security audit · public repository · Microsoft Store |

Out of scope, on purpose: anything that needs a server (team views, sync between PCs).
