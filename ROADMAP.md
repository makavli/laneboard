# Roadmap

Free to make, free to use: everything runs on the user's PC, no server, no account, no telemetry.

| Milestone | Status | Goal |
|---|---|---|
| 0.1 First light | done | Tray flyout, Light/Advanced views, themes, glass-to-solid, GitHub through `gh` |
| 0.2 Solid | done | Opens on the tray's monitor and taskbar side · instant updates on file changes · crash log |
| 0.3 Needs-you | done | Windows notifications (checks fail/pass, new safe point, runner offline) · tray badge · needs-you first |
| 0.4 Polish | done | Pin projects · refresh interval · subtle motion · keyboard navigation · accessibility pass |
| 0.5 Ship-ready | done | MSIX with a startup task and a command alias · Store screenshots · privacy text (README GIF moved to 1.0: needs a screen recording) |
| 1.0 | planned | README GIF · Store listing images · security audit · public repository · Microsoft Store |

Out of scope, on purpose: anything that needs a server (team views, sync between PCs).
